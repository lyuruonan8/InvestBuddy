# InvestBuddy

面向个人投资研究者的本地 Streamlit 工作台。第一阶段提供规则规划、工具执行、证据追溯及 SQLite 任务历史。

## 启动

在项目目录运行以下 PowerShell 命令。已安装依赖时可直接运行最后一行。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --index-url https://pypi.org/simple -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1 --server.port 8501 --server.headless true --browser.gatherUsageStats false
```

默认启动模式为 `public-demo`，用于公网测评，仅使用明确标注的合成数据。打开 http://127.0.0.1:8501，提交预设任务并点击「批准运行演示」。默认日期覆盖合成样本。每个连接使用独立临时 SQLite，重新连接或重启可能丢失记录。请勿将本机数据库上传。

如需在可信本机使用东方财富和原有 SQLite，在同一 PowerShell 先运行：

```powershell
$env:INVESTBUDDY_PROFILE = 'local'
```

重启本机服务后，打开 http://127.0.0.1:8501，选择「真实数据 · 东方财富」，点击「创建并运行研究」，然后点击「批准真实取数」。真实模式仅支持宁德时代 300750.SZ，最长研究区间为 366 天。研究区间筛选报告期和交易日，财务记录可能在区间结束后披露；该功能不用于历史时点回测。数据库文件为 investbuddy.sqlite3。

## 数据与执行边界

- 真实模式联网读取东方财富数据中心公开 JSON 端点。利润表使用 `TOTAL_OPERATE_INCOME`、`PARENT_NETPROFIT` 及披露日期 `NOTICE_DATE`。估值使用历史交易日 `PE_TTM`。接口不要求本地密钥，公开端点的字段和可用性可能变化。
- 保存供应商、请求地址、字段名、查询 UTC 时间、数据时点、财务报告期、披露日、单位和口径。估值数据对应交易日。来源链接可重发原查询；保存的证据值反映任务查询当时的响应。
- 财务原始值采用累计口径。归母净利率 = 累计归母净利润 / 累计营业总收入。同比使用上一年相同报告期且基数为正的记录。估值变化 = 区间末个有效交易日 PE TTM 减去首个有效交易日 PE TTM。
- 数据质量以区间有效结束日为基准，财务超过 150 日、估值超过 10 日标为过期。缺失、过期或冲突时保留原始证据，抑制受影响指标的结论。当前真实数据只有一个供应商，冲突检测用构造数据测试。
- 真实请求异常时保留失败状态。可另建「演示 · 合成数据」任务，选择 2026-01-01 至 2026-06-30 查看构造样本。两种模式分别保存。
- 扶摇与 iFinD MCP 未集成。当前真实模式无需环境变量或模型密钥。规则规划按目标选择财务查询、估值查询或本地待核验风险梳理。报告由确定性模板生成。风险方向需要公告或管理层材料核验。
- 每步执行前后持久化。失败或进程中断后，从历史任务选择「从检查点继续」。已完成步骤复用原结果，运行中断的步骤会重试。每个任务同时只允许一个执行进程。
- 真实任务须先批准向东方财富发送证券代码及区间。批准保存在任务中，续跑沿用同一批准。取消请求也会写入 SQLite，执行器在当前调用返回后停止。
- 默认工具预算 4 次，执行时延预算 45 秒，可在创建时调整。预算按 Agent 工具计数，一次东方财富取数包含两个 HTTP 请求；尝试在发起前计入。时延在步骤边界检查，每个 HTTP 请求使用 10 秒 socket 超时。进程强制终止时，尚未写入的步骤耗时无法计入。
- 执行日志记录审批、执行、取消、停止和失败事件，以及已返回步骤的耗时。当前为本机单用户工作台，暂无用户身份隔离和费用计量。

## 研究线程与规划

- 新任务默认创建研究线程。选择历史线程可追问并查看该线程任务。追问默认沿用线程股票代码与区间。需要变更区间时，明确勾选并设置日期。早期独立任务可从线程选择器单独查看。
- 线程上下文只引用同线程记录。超过页面设定的近期任务数后，更早任务以确定性摘要提供任务引用、证据编号和日期、完成步骤、未解决问题与审批记录。摘要保留原始引用，体积仍会随线程历史增长。后续查询继续使用实时数据工具。
- 跨线程偏好仅支持主动保存的预设选项，可查看和删除。任务文本存在本地 SQLite，输入框提示勿填写敏感内容，常见个人持仓和账户词汇会触发拦截。
- 真实 LLM 尚未接入，当前研究规划使用规则规划器。可插拔 provider 实现 `generate(context)` 并返回 JSON 字符串，结构为 `{"tools":[{"tool":"research.scope","arguments":{"topic":"financial"}}]}`。仅支持已注册的范围工具和 `financial`、`valuation`、`risk` 参数。Python 编译并执行计划，工具审批和预算由执行器控制。Mock 仅供测试。模型失败或响应无效时使用带标记的规则规划。
- 财务任务只请求利润表，估值任务只请求交易日 PE，风险任务整理待核验方向。结合两类数据的取数最多发送两个 HTTP 请求；风险梳理也占一次 Agent 工具预算。

## 测试与 AI 使用

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

测试覆盖原演示链路，以及使用合成接口夹具验证真实适配器的正常响应、证据回溯、缺失、过期、来源冲突和超时。自动化测试默认离线运行。2026-11-12 在本机 `local` 模式下使用 Streamlit AppTest 实际请求东方财富，验收证据、指标及估值图渲染，再单独验证合成演示任务。
Codex 用于读取题目、查阅数据入口、编写和运行代码与测试。候选人复核与修订记录待实际检查后补充。
